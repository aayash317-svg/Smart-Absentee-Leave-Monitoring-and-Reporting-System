# Smart Absentee Leave Monitoring System - Database

## Database
- MongoDB
- Database Name: `smart_absentee_db`

## Collections
1. users
2. departments
3. students
4. absentees
5. leaveApplications
6. fineRules
7. finePayments
8. notifications
9. auditLogs
10. reports

## Setup
1. Create the database.
2. Create the collections.
3. Run `create_indexes.js`.
4. Apply the validation rules.
5. Run `seed_data.js`.
